# Task 06 — Dashboard, Live Monitoring, and Fraud Reporting

## Goal
Provide a dashboard for live traffic, fraud incidents, suspicious IPs, exclusions, and reporting over time so the client can trust the system.

## Current status in repo
Currently missing:
- Frontend dashboard application.
- Live monitoring for sessions and risk trends.
- Fraud table, IP reputation insights, and campaign-level views.
- Search/filter/reporting API endpoints.
- Client feedback and review flows.

## Deliverables
- Dashboard UI with overview metrics and fraud insights.
- Traffic, session, and fraud tables.
- Live filters by account, website, campaign, and verdict.
- Exclusion and campaign protection reports.
- Downloadable reports and reasoning breakdowns.

## Acceptance criteria
- A user can view total traffic, suspicious sessions, and protected IPs.
- Fraud reasons and risk scores are visible per session.
- High-risk sessions can be investigated with supporting metadata.
- Dashboard data is connected to backend analytics endpoints.
